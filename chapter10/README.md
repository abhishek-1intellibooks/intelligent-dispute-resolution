# Chapter 10: Outcome Prediction and Recovery Optimization

This chapter decides which worked disputes are worth contesting and what each one is worth. A win model is trained on the analysts' contested cases, which are plentiful but biased because analysts chose cases they felt good about. It is then calibrated with Platt scaling on a small random exploration sample, which is the only unbiased view of what contesting achieves. Calibrated probabilities become expected values through Chapter 6's formula, `EV = p × A − c − q × V`. `fight_or_accept.py` turns each expected value into contest, accept or review, using a review band, the network time limit and a capacity cut. `policy_eval.py` replays September to December under six policies and also shows how a segment drifts after a network rule change.

> All data are synthetic and every amount, fee and result is illustrative.

## Files

| File | Purpose |
|------|---------|

| `policy_eval.py` | Listing 10.5. Replays the four test months under six policies, with exploration-only estimates (Table 10.6), the ranking curve (Figure 10.6) and monitoring by segment (Figure 10.7). Writes Figures 10.4 to 10.7. |

| `tests/test_chapter10.py` | pytest tests for the registry, calibration helpers and the rule precedence of Table 10.5. |
| `requirements.txt` | Packages for this chapter. |

## How to run

```bash
cd chapter10
python make_outcome_data.py      # writes contest_history.csv
python train_outcome.py          # Table 10.3, writes outcome_logistic_platt.joblib
python fight_or_accept.py        # decisions for September to December
python policy_eval.py            # Table 10.6, Figures 10.4-10.7
python worked_example.py         # Table 10.8
python -m pytest -q              # 7 tests
```

## Chapter artifact

`fight_or_accept.py` is the contest-or-accept decision module. For each case it returns the calibrated probability of winning, the expected value, the break-even amount, the decision, the reason and the model version.

### Known gaps from the book's numbers

- **Policy ranking.** The ranking matches the book, but historical practice nets more here ($163k against $133k), so it edges out "contest everything" ($156k).
- **Exploration estimates.** Here they run 1–5% low. In the book they run 9–33% high. In both they rest on only 663 cases.
- **Rule-change drift.** The drift after 1 October is stronger here (a drop of about 20 points). Other reasons are under-predicted by about 2 points, so the policy's total shortfall against expectation is $15,683. Fraud cases after the change account for −$49,663 of that, and the other contests realize $33,979 more than predicted. The book has a $51,851 shortfall, 76% of it from fraud.
- **Time limit.** 17 test cases fall past the time limit (book: 9).
